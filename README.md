# בונה המערכת – מכללת בראודה

אתר לבניית מערכת שעות למכללת בראודה, עם בנייה אוטומטית של המערכת הטובה ביותר.
ברירת המחדל היא **תשפ״ז (2027) – סמסטר א׳**.

## מה יש באתר

- **בחירת מגמה ושנת לימודים.** האתר מציג רק את הקורסים של המגמה שלכם: קורסי חובה לשנה שבחרתם, ובנוסף קורסי בחירה וקורסים נוספים במגמה. קורס שמשותף לכמה מגמות יופיע בכל אחת מהן. אפשר גם לחפש בכל הקורסים.
- **דף קורס.** בכל קורס יש תיאור מהידיעון, נקודות זכות ושעות שבועיות, וכל הקבוצות עם מרצים, מועדים וחדרים, כולל סימון של קבוצה מלאה. הסילבוס (PDF) מוצג בתוך האתר. הכפתור "פתח את דף הקורס באתר המוסד" פותח את הדף הרשמי **של השנה הנכונה**.
- **לוח שבועי אינטראקטיבי** לימים א׳–ו׳, בשעות 08:00–23:00. הוספה והסרה של קורסים, החלפת קבוצה בלחיצה על משבצת מקווקוות, סימון התנגשויות באדום, וסיכום של נ״ז, שעות, ימים וחלונות.
- **✨ בנייה אוטומטית.** בוחרים קורסים ומטרה: כמה שפחות ימים, ימים קצרים, בלי חלונות, או קצת מהכול. אפשר גם להגדיר:
  - ימי חופש שבהם לא תהיה אף שעה;
  - שעת התחלה ושעת סיום;
  - הימנעות מקבוצות מלאות;
  - נעילה של קבוצות שכבר בחרתם.

  הבונה עובר על כל השילובים החוקיים: הרצאה אחת לכל קורס, ותרגיל או מעבדה מתוך הקבוצות שמקושרות להרצאה שנבחרה. הוא מציג את המערכות הטובות ביותר עם תצוגה מקדימה על הלוח.
- חדרים פנויים, מצב כהה, תמיכה בטלפון, הדפסה וקישור לשיתוף המערכת.

## הרצה

צריך Node.js בגרסה 20 ומעלה. אין תלויות חיצוניות.

```bash
npm install        # לא מתקין כלום, אבל לא מזיק
npm run scrape     # מוריד את נתוני 2027 מהידיעון של בראודה (כ-10 דקות בפעם הראשונה)
npm run dev        # http://localhost:5173
```

עוד פקודות שימושיות:

- `npm run scrape:fresh`: סריקה מחדש בלי להשתמש במטמון.
- `node scraper/scrape.mjs --year 2026`: סריקה של שנה אחרת. השנה תתווסף לבחירה באתר.
- `npm test`: בדיקות לבונה האוטומטי, כולל הרצה על הנתונים האמיתיים.

## מאיפה הנתונים

כל הנתונים נלקחים מתחנת המידע הציבורית של המכללה (`info.braude.ac.il/yedion`):

| נתון | מקור |
|---|---|
| רשימת הקורסים שנלמדים השנה | חיפוש לפי אות ראשונה (`S_LOOK_FOR_NOSE_AB`) ומערכת השעות המלאה (`S_YFineDate`) |
| קבוצות, מועדים, חדרים, קבוצות מקושרות ותיאור | דף הקורס (`S_LOOK_FOR_NOSE`) |
| שיוך למגמה ולשנה | קבוצות הלימוד של כל מגמה (`S_GROUP`) ותוכניות הלימודים (`S_PROG` → `S_SHOW_PROGS`) |
| סילבוס | `https://info.braude.ac.il/info/<שנה>/<מספר קורס בן 7 ספרות>.pdf` |

לגבי הסורק:

- הוא שולח בערך בקשה אחת בשנייה ושומר את התשובות בתיקייה `cache/`, כך שהרצה חוזרת באותו יום מהירה מאוד.
- אם דף קורס בידיעון לא מחזיר קבוצות, הסורק מנסה את braude.top כגיבוי.
- הידיעון שומר את השנה בסשן, ולכן הסורק בוחר את השנה לפני כל סריקה. מאותה סיבה, הקישורים לאתר המכללה נפתחים דרך מעבר שנה אוטומטי.

## מבנה

```
scraper/      הסורק: firefly.mjs (לקוח לידיעון), parse.mjs, scrape.mjs, braudetop.mjs (גיבוי)
public/       האתר (HTML/CSS/JS בלי בנייה)
  js/model.js       כללי הקבוצות: הרצאה ותרגיל/מעבדה מקושרים
  js/optimizer.js   חיפוש עם גיזום (branch and bound) שרץ ב-Web Worker
  data/             קובצי ה-JSON שהסורק יוצר
server.mjs    שרת סטטי קטן, ובדיקה אם קיים סילבוס
research/     מחקר מקדים: findings.md ודוגמאות
```

## טיפים

- **קורס שמותר לו לחפוף לקורסים אחרים:** בלשונית "הקורסים שלי" יש לכל קורס את האפשרות "לאפשר חפיפה". זה מתאים למשל למעבדה שמתקיימת אחת לשבועיים: הידיעון לא מציין שבועות מתחלפים, ולכן בלי הסימון שתי מעבדות כאלה ייראו כהתנגשות.
- **קורס שבו התרגול מופיע בתוך שעות ההרצאה:** כך הוא רשום בידיעון, ולכן זו לא נחשבת התנגשות.
- **מגמות ותמיכה בשנה:** "הקורסים של שנה X" כוללים את הקורסים ששובצו השנה במערכת של קבוצת השנה הזו, ואת הקורסים שתוכנית הלימודים מגדירה כחובה לאותה שנה. התגית "חובה" מגיעה מתוכנית הלימודים, והתגית "במערכת שנה X" מגיעה מהשיבוץ בפועל.
- **הסילבוס בתוך האתר:** הסילבוס מוצג כטקסט נקי וקריא. אפשר לעבור לעמודי ה-PDF המקוריים בלחיצה.

## מגבלות ידועות

- **הכפתור "פתח את דף הקורס באתר המוסד" פותח לשונית חדשה:** קודם הוא מחליף בה את השנה ל-2027, ואחרי כשתי שניות הוא מעביר אותה לדף הקורס. אם הדפדפן חוסם חלונות קופצים, תופיע הודעה.
- **בחירה של כל הקורסים של קבוצת שנה מסוימת:** חלק מקבוצות השנה כוללות כמה קורסי בחירה או התמחויות שמתקיימים באותה שעה. אם בוחרים את כולם יחד, אין מערכת ללא התנגשויות, וזה המצב האמיתי בידיעון. הבונה יודיע על כך.

- סמסטר ב׳ של תשפ״ז עוד לא פורסם במלואו בידיעון: יש קבוצות, אבל עדיין בלי שעות. כשהשעות יפורסמו, מריצים שוב את `npm run scrape`.
- מועדי בחינות עדיין לא פורסמו בידיעון לשנת 2027, ולכן הם לא מוצגים.
- שיוך הקורסים למגמות מבוסס על הנתונים הרשמיים. קורסי בחירה כלליים, כמו לימודים כלליים ואנגלית, מופיעים תחת "חוג כללי" או בחיפוש בכל הקורסים.
- בטלפון חלק מהדפדפנים לא מציגים PDF בתוך הדף. במקרה כזה יש כפתור לפתיחת הסילבוס בלשונית חדשה.
